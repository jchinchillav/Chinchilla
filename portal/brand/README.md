# Chinchilla · Brand assets (extraídos del PDF del diseñador, 16 oct 2026)

Fuente: `_fuente_update_chinchillabrand_2026-10-16.pdf` (Adobe Illustrator, vector, texto en trazos).
Cada composición existe en **positivo** (Graphite Ink #1D1D1F sobre transparente) y **negativo** (blanco sobre transparente), en tres formatos:

| Formato | Uso |
|---|---|
| `.svg` | Vector editable; recolorear cambiando el `fill` del grupo `<g>` |
| `.pdf` | Vector para proveedores de transfers, CIPO (marca figurativa) y bordado |
| `.png` | 4000 px de ancho, fondo transparente, para web, redes y mockups |

| Composición | Archivo base |
|---|---|
| Logo arriba + nombre abajo, relleno sólido (**principal**) | `chinchilla_vertical_solido_*` |
| Logo arriba + nombre abajo, versión en línea | `chinchilla_vertical_linea_*` |
| Horizontal, sólido | `chinchilla_horizontal_solido_*` |
| Horizontal, línea | `chinchilla_horizontal_linea_*` |
| Isotipo solo, sólido (transfers de silicona, favicon, etiqueta) | `chinchilla_isotipo_solido_*` |
| Isotipo solo, línea | `chinchilla_isotipo_linea_*` |
| Wordmark solo | `chinchilla_wordmark_*` |

Color de marca en el PDF del diseñador: relleno `#D7BBC6` sobre fondo `#E5C0C7` (tono sobre tono). Para versiones en color, cambia el `fill` del SVG por el Pantone/HEX de la paleta oficial.
